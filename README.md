# Платформаи «Пайравони Пешвои миллат» — прототипи аввал

## Оғози кор
1. Файлҳои `index.html`, `style.css`, `app.js` ва ҷузвдони `assets`-ро якҷоя нигоҳ доред.
2. Барои санҷиши маҳаллӣ `index.html`-ро тавассути сервери маҳаллӣ кушоед (масалан `python -m http.server 8000`).
3. Дар браузер `http://localhost:8000` кушоед.

## Ҳисобҳои демо
- Super Admin: `super` / `super123`
- Admin: `admin` / `admin123`
- Донишҷӯ: аввал бақайдгирӣ кунед, баъд Admin дархостро тасдиқ кунад.

## Функсияҳои прототип
- Бақайдгирии донишҷӯ ва тасдиқи Admin.
- Интихоби донишгоҳ ва курс ҳангоми бақайдгирии донишҷӯ.
- Рӯйхати 30 дарс; Admin номи дарс ва маълумоти онро ворид мекунад.
- Сохтани QR барои дарси интихобшуда ва қатъ кардани он.
- Скан кардани QR бо камера аз кабинети донишҷӯ.
- Сабти иштирок, ҳисобот ва содироти CSV.
- Эълонҳо ва танзимоти Super Admin.

## Маҳдудияти муҳим
Ин версия прототипи фронтендӣ барои намоиш ва санҷиши ҷараёни интерфейс аст. Маълумот дар `localStorage`-и браузер нигоҳ дошта мешавад; он байни дастгоҳҳои гуногун ҳамоҳанг намешавад ва барои истифодаи воқеӣ бо маълумоти шахсӣ бехатар нест. Ҳисобҳои демо низ танҳо барои намоишанд. Барои ба кор даровардани воқеӣ backend, пойгоҳи додаҳои серверӣ, авторизатсияи бехатар, HTTPS, идоракунии ҳуқуқҳо ва QR-токени серверӣ бояд илова шаванд.

QR generation ва scanning китобхонаҳои берунаи CDN-ро истифода мебаранд, бинобар ин барои ин ду функсия пайвасти интернет лозим аст.
